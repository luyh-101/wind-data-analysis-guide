# 用风速估算同期功率

**功率曲线**表示机组正常运行时，不同风速通常对应多大的有功功率。把某段时间已经测到的风速放进这条曲线，就能估算同一时段的功率。

## 怎样建立功率曲线 {#怎样画曲线并比较误差}

1. **把风速和实测功率对上。** 用同一机组、同一时段的数据，从正常发电的记录中选建模样本。启停和限功率时的出力另行看。
2. **看不同风速下通常发多少。** 把相近的风速放到同一组，分别取该组的平均风速和平均功率。把相邻、数据充足的组连起来，得到一条风速–功率曲线。输入风速落在两个曲线点之间时，按它离两边的远近取中间功率。超出范围或中间缺数据时，单列为暂无法估算。
3. **拿另一段记录试算。** 用一段没参与建模的历史记录，把实测风速代入曲线。比较算出的功率与当时实际发出的功率，报告差多少、能估算多少时段。

有足够的可比记录时，可以用同一批实测功率分别配对机舱风速和雷达风速，建立两条曲线，再用两条都能估算的共同验证时段比较。雷达记录暂时不足时，先用机舱风速和同期实测功率跑通方法。用雷达风速做后评估前，再用同期雷达与功率记录建立并验证对应的模型。

## 估算结果有什么用 {#曲线应用与功率预测}

把已验证的曲线用于对应来源的现场实测风速，就能得到参考功率。平均功率乘以时间得到参考电量，再和相同机组、相同时段的实际电量比较。
