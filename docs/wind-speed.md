# 两路实测风速对照

要比较的是**同一时段**机舱和现场激光雷达各测到了多大的风速。机舱风速反映机组附近的气流，雷达反映指定位置和高度的风况。先确认雷达测的是哪一层、对应哪台机组，以及机舱读数有没有经过修正。

## 对齐时间，再算风速差 {#怎样配对和拟合}

1. **对齐时间。** 统一时区、单位和[实际覆盖的时间段](/scada#时间戳采样间隔与统计窗口)。如果一方给十分钟均值，而另一方每隔几秒记录一次，就把较密的记录汇总到同一段十分钟。两路都有有效读数才比较。
2. **逐段相减。** 统一用 **机舱风速 − 雷达风速**。比如同一时段机舱为 7 m/s、雷达为 8 m/s，差值是 **−1 m/s**，表示机舱读数低 1 m/s。差值为正时，机舱读数更高。
3. **看差异出现在哪里。** 把各时段的差值放到时间轴上。报告有多少时段能比、哪一路经常偏高、通常差多少。正负差值可能抵消，平均差接近零时，还要看把每段差值取绝对值后的平均。必要时按风向或风速范围分别看。

逐段差值回答“同一时段差多少”，单位是 m/s。[两路风频比较](/wind-frequency#两路风频怎么比)则回答“哪一路更常落在某个风速区间”。

## 什么时候需要做风速换算 {#留出时段验证与适用范围}

确实需要用一路风速估算另一路时，再用配对记录拟合换算关系。比如要从机舱风速估算雷达风速，就以机舱读数为输入、雷达读数为比较对象。留一段未参与拟合的记录，比较换算前后与雷达实测相差多少。估算误差用“估算值减实测值”表示，平均绝对误差是把每段误差取绝对值后再平均。
