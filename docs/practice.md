本章的方法用于回答常规散点图和功率曲线之后的问题，例如转速点带在哪个控制阶段形成、机组怎样通过某段转速区间、技改前后是否具备可比条件。按手头的信号、采样间隔和机组资料选用对应专题。

## 控制表现与多信号复核

当相近风速下出现多条转速或角度点带，可将同一批记录按控制版本、运行状态和功率设定分组，再用[三张散点图](/operations#三张散点图的联合判读)辨认差异出现在哪个阶段。如果分层只在启停或限功率时出现，应优先回查相应状态切换。若同一运行阶段内仍存在差异，则比较指令与反馈时序，定位设定变化或响应偏离的时刻。转速限制和桨距角设定的具体含义以该机型的控制文件为准。

### 转速–扭矩与共振穿越 {#转速扭矩与共振穿越}

当转动产生的周期激励接近结构的固有频率时，振动可能增大。分析穿越过程所用的转速区间由机组技术文件给出。先确认区间对应风轮、主轴还是发电机转速。绘图时，转速与扭矩（力矩）应对应同一传动轴侧，例如都取发电机侧。若两个信号分属齿轮箱两侧，应按机组资料换算到同一侧，并让图中标注的转速区间与横轴采用同一口径。注明扭矩来自实测、估算还是控制指令。

1. **用散点图定位区间。** 以转速（r/min）为横轴、扭矩（N·m 或 kN·m）为纵轴。按机组分面，统一坐标和工况配色，用阴影标出规定区间。密集点带表示该区域记录较多，空区也可能来自工况、采样或覆盖差异。用时间戳回到原始记录。
2. **用时序识别穿越。** 从区间一侧进入、再从另一侧离开，记为完整穿越。同侧离开记为折返，遇到缺测或状态切换时单独标记。退出时刻减进入时刻得到停留时长。区间宽度除以穿越时长可估计平均穿越速率。只有分钟均值时，主要分析转速分布和覆盖，短时穿越需要更密的记录。
3. **结合其他信号解释。** 在同一时间段对照扭矩、振动、控制状态和告警。跨机组比较时还要统一风况和控制条件。避振效果由控制与结构专业人员结合振动、载荷和控制设计判断。

::: details 转速–扭矩图的 Python 绘制模板

以下函数接收完成字段映射、工况筛选和单位转换的记录。`speed_rpm` 和 `torque_nm` 对应同侧转速与扭矩，`rpm_low` 和 `rpm_high` 使用对应机组的技术参数。

```python
import matplotlib.pyplot as plt


def plot_speed_torque(records, rpm_low, rpm_high):
    groups = list(records.groupby("turbine", sort=True))
    fig, axes = plt.subplots(
        1, len(groups), squeeze=False, sharex=True, sharey=True,
        figsize=(4.5 * len(groups), 3.8), layout="constrained"
    )
    for ax, (turbine, rows) in zip(axes[0], groups):
        ax.axvspan(rpm_low, rpm_high, color="#d4dce0", alpha=0.7)
        ax.scatter(rows["speed_rpm"], rows["torque_nm"], s=7, alpha=0.35)
        ax.set(title=str(turbine), xlabel="Speed (rpm)")
    axes[0, 0].set_ylabel("Torque (N·m)")
    return fig
```

共用阴影区间适用于规格和控制设置一致的机组。若区间不同，用各机组的上下限分别标注，并保持坐标一致。

::: details 穿越事件的识别与程序验证

1. **划分连续片段。** 按机组和时间排序。遇到记录缺失、时间间隔超过允许值、工况切换或控制版本切换时断开。允许间隔应根据原始采样周期确定。按技术文件的转速下限和上限，把有效样本分为区间下方、区间内和区间上方，等于边界的样本计入区间内。
2. **记录进入和退出。** 从某一侧进入区间时，记下进入侧及时间。回到同一侧记为折返，从另一侧离开记为完整穿越。片段开始或结束时已在区间内、途中发生中断，分别标记缺少进入或退出边界。相邻采样点直接从一侧跳到另一侧时，标记为“跨区、无区间内样本”，单列其时间分辨率。
3. **计算停留时间。** 进入和退出的实际时刻各落在一对采样点之间。采样足够密且局部转速近似连续时，可在相邻点之间插值求过界时刻。完整穿越的时长为退出时刻减进入时刻。注明估计方法、采样间隔、方向和状态。

程序测试样例覆盖四类输入。“下方 → 区间内 → 上方”应识别为完整升速穿越，“下方 → 区间内 → 下方”应识别为折返，“下方 → 区间内 → 缺测”应识别为中断。相邻点直接跨区时，应单列没有区间内样本的情况。

用图中的每秒 8、9.5、10.5、12 r/min 序列验证插值。测试区间为 9–11 r/min，预期在第 0.67 秒进入、第 2.33 秒离开。用未取整的时刻相减，停留约 1.67 秒。

### 振动、温度与偏航的辅助图表

偏航是机舱绕塔筒轴线转动以调整朝向。辅助图应围绕已定位的问题选用，例如在角度反馈迟滞的时段查看对应驱动器的温度或电流。

| 信号 | 制图方法 | 判读要点 |
| --- | --- | --- |
| 振动 | 按测点和方向分别绘制风速–振动散点图与分箱统计线，例如塔筒前后向、左右向。检查共振时另画转速与振动的同步时序。 | 统一量纲、测点及统计量，例如窗口最大值或均方根。画预警和故障线时，使用设备给定的同口径阈值。 |
| 温度 | 对变桨驱动或其他与当前问题相关的测点，画功率–温度散点及分箱趋势。再按相近环境温度和负荷，对照本机历史、同型机组或同机各叶片。 | 温升偏离可用“实测温度减同工况参考温度”表示。用时序查看持续性，再核对驱动动作、告警和检修。 |
| 偏航误差 | 按风速、风向扇区及偏航状态画风速–相对风向角散点图，叠加分箱中位数。 | 先确认相对角的正负方向。用绝对风向和机舱朝向计算角差时，将差值折回同一角度区间，如 [−180°, 180°)。独立测风可辅助核查持续偏差。 |

跨机组比较时统一轴范围、测点和统计口径。

## 低出力筛查与损失归因

先按可比风速、风向和运行状态找出持续低出力的窗口，再把功率残差与功率设定、限发事件和逐叶片角度时序对齐。如果角度偏离和低出力的起止时间接近，可进一步检查是否出现指令跟踪偏差、状态切换或测风问题。损失计算和事件优先级采用[后评估章节的分段归因方法](/assessment#发电量损失与低效分析)。

## 可利用率与事件统计

批量处理时，先把同一次停机的多条告警归并为一个事件，保留起止时间、主因、恢复状态和未闭合标记。这样同一事件只计一次，时间可利用率和电量可利用率也能使用一致的事件分类。 [可利用率和故障指标](/assessment#可利用率与可靠性)

## 技改对照方法

技术改造前后的平均功率可能同时受风况、限发和设备状态影响。先确定变更时间和目标机组，再根据可取得的测风或参考机组数据选择对照方法。

| 数据条件 | 对照方法 | 核查重点 |
| --- | --- | --- |
| 技改前后风速口径可比 | **功率曲线比对。** 用相同风速箱比较前后曲线。有同期参考机组时，一并比较其前后变化。 | 先用同期参考测风或可比机组核对测风关系。核查控制版本、风向、空气密度、季节和正常样本覆盖。 |
| 有同期未技改的可比机组 | **功率传递法。** 用技改前双方正常运行的同期样本建立“参考机组功率 → 技改机组功率”的关系。将技改后的参考机组功率代入，得到无技改时的估算基准，再与技改机组实测功率比较。 | 按风向和出力区间核查关系。用留出的技改前时段检验基准误差，汇总技改后双方均符合评价条件的窗口。 |
| 技改影响机舱测风，有稳定的参考风速 | **风速传递法。** 用技改前同期记录建立参考测点与技改机组的风速映射，再用技改后的参考风速重建可比的风速输入并绘制功率曲线。 | 检查参考测点是否受技改后的尾流影响，并按风向扇区和风速区间检查映射误差及覆盖。 |
| 全场实施或缺少合适的参考机组，有独立来流测风 | **同风况电量对照。** 用独立测风选择前后可比的风速、风向和工况，再用统一计量边界比较电量。比较期时长或风频分布不同时，按共同风况权重折算。 | 区分风资源变化、可利用率、限发和发电性能变化。列出覆盖范围和选用的权重。 |

判读技改结果时结合各风速箱的功率变化、共同覆盖和基准来源。比较年发电潜力时使用同一份长期风频。

### 参考机组传递计算

1. **检查参考条件。** 确认参考机组未随同技改，其测点、控制、调度和可用性在前后时段可比。核对更换风速仪、偏航策略变化和技改后尾流是否会影响参考量。可用独立测风或另一台未改机组辅助检查参考关系。
2. **拟合技改前关系。** 将参考和目标按时间对齐，筛选双方正常发电的窗口。按目标选择“参考功率到目标功率”或“参考风速到目标风速”的映射。先在留出的技改前时段按风向和量级核查误差及覆盖，再确定可用区间。
3. **估算技改后的对照值。** 功率传递法用同期参考功率估算无技改基准，以实测目标功率减该基准。风速传递法先把技改后参考测风换算为目标的可比风速，再用该风速及技改后的实测功率建曲线，与技改前同口径曲线比较。应用时筛查参考条件变化和范围外样本。
4. **换算电量。** 将各有效窗口的功率差乘以窗口时长并求和，得到比较期间的电量差。长期折算时，先用独立且可比的测风数据按风速分箱，再按同一份长期风频和评价期小时数加权，并注明共同覆盖的风频权重。只有参考功率数据时，可先报告比较期间的电量差。长期折算还需要与分箱变量对应的代表性权重。

## 缺测处理与分析工具验收

风速或功率缺测时，先按用途决定是否补值。需要估算电量或做敏感性分析时，可用同期参考机组或独立测风建立映射，在留出的实测窗口评估补值误差。保留缺测与补值标记，性能验证优先使用实测样本，单列补值结果。

分析工具验收用可复算的正常、异常和缺测记录，逐项核对工况标记、事件时间、拟合与验证数据划分、曲线范围、误差和输出表。更换机型或数据来源时，复核字段映射、状态字典和规则版本。现场控制与保护功能评价还需依据机组技术文件、规定的试验条件和记录。

验证时可选取三类容易影响结果的记录：跨两个窗口的停机事件、同一时段的多条告警、超出曲线覆盖范围的测风。分别核对分段时长、主事件归并及功率估算的有效性标记。使用同一输入和配置复跑，核对关键结果是否一致。

可先用[停机与限功率事件重叠示例](/assessment#复算示例-停机与限功率事件重叠)核对时间分段。将窗口在第 6 分钟切成两段后重新汇总，限功率和故障的累计损失仍分别为 20 和 80 kWh。对故障事件重复导入一条相同记录，再检查归因时长和损失是否保持一致。

## 分析程序与控制信号复核

| 程序环节 | 实现要点 |
| --- | --- |
| 数据接入 | 为每种数据来源维护字段、单位、采样周期和状态码映射。按机组与时间窗口对齐，保留原值、质量标记和筛选原因。 |
| 指标计算与批量制图 | 按机组、叶片和工况分组，计算角度偏差、转速分布、功率分箱均值和误差。保存绘图数据，便于从图上的点查回原始记录。 |
| 事件回查 | 把候选时段与告警、功率设定、变桨指令和反馈连接。比较时采用相同采样口径，查看异常前后及相似工况的记录。 |
| 控制逻辑核对 | 有控制说明和较细记录时，可回放状态、设定与反馈时序，复算触发条件、响应延时和恢复时间。控制参数评价、策略变更及现场测试由相应专业人员按设备要求执行。 |

::: details 逐叶片散点图的 Python 示例

下载站内逐叶片 CSV 后，将它与脚本放在同一目录。示例用 pandas 和 Matplotlib，机组间共享坐标轴，三片叶片共用配色规则。

```python
import matplotlib.pyplot as plt
import pandas as pd

data = pd.read_csv("kelmarsh-blade-pitch.csv")
turbines = list(data.groupby("turbine", sort=True))
fig, axes = plt.subplots(
    1, len(turbines), squeeze=False, sharex=True, sharey=True, layout="constrained"
)
for ax, (turbine, rows) in zip(axes[0], turbines):
    for blade, color in zip("abc", ["#3069a2", "#d38124", "#1e836a"]):
        ax.scatter(
            rows["wind_ms"], rows[f"pitch_{blade}_deg"],
            s=7, alpha=0.35, color=color, label=f"Blade {blade.upper()}"
        )
    ax.set(title=turbine, xlabel="Wind speed (m/s)")
axes[0, 0].set_ylabel("Pitch angle (deg)")
axes[0, 0].legend()
plt.show()
```
